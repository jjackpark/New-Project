### adversarial-reviewer 재검토 및 수정 (2026-09-17)

- **C1(치명)**: `navigator.clipboard`는 secure context(HTTPS/localhost)에서만 존재 — SPEC상 배포 형태(사내망 `http://서버IP`)에서는 항상 `undefined`라 복사 버튼이 실사용자 전원에게 100% 실패했음. `document.execCommand("copy")` 폴백(textarea 전체선택 후 복사) 추가, 그마저 실패하면 텍스트 전체선택 상태로 남겨 수동 Ctrl+C를 유도. `window.isSecureContext = false`로 스텁해 실제 브라우저에서 폴백 경로가 정상 동작함을 확인(자동 선택 + 복사 성공 토스트).
- **M4**: 날짜 입력을 비우면 버튼 라벨/카드 제목이 빈 문자열이 되고 모달 제목과 본문 날짜가 어긋나는 문제 — `effectiveDate`(비어있으면 오늘로 폴백)를 표시/모달 호출 전부에 일관 적용. 인원수 입력 중 날짜가 비어있으면 저장을 막고 토스트 안내.
- **M5(중요)**: 인원수 입력 후 blur로 `change`가 발생 → 전체 `render()`가 DOM을 통째로 교체 → 바로 이어지는 "리포트 생성" 클릭이 씹히는 문제(mousedown/mouseup 사이 노드 교체) — 전체 재렌더 대신 합계 텍스트(`#vendor-total`)만 직접 갱신하도록 변경. 실제 브라우저에서 "인원수 변경 → 곧바로 리포트 버튼 클릭" 시퀀스로 재현·수정 확인.
- **M1**: 업체 합계가 화면에 나열된 값의 합과 다를 수 있던 문제 — `vendors` 기준으로만 합산.
- **M6**: 다른 뷰(equipment/issues/masterplan/qual/vendors)는 전부 `App.ui.fitSpan`으로 텍스트 짤림 방지 1~3단계를 쓰는데 이 화면만 `escapeHtml` raw 출력이었음 — 설비명/업체명 셀에 `fitSpan` 적용, `render()` 끝에 `App.ui.applyFit(el)` 호출 추가(내부 재렌더 때마다 폭 재계산되도록).
- **M10**: 같은 설비/같은 날짜 일보 중복 등록이 가능했고 중복분은 리포트에서 조용히 사라졌음 — 저장 전 중복 체크 추가.
- 사소: 내용 textarea에 `maxlength="200"` 추가, `bindForm` 미사용 4번째 인자 제거.

**남겨둔 항목**: M8(mock 아키텍처)은 tasks/T045.md 노트 참고, 이 태스크 범위 아님. M12(테스트 0건)는 저장소에 테스트 인프라가 없어 범위 밖.
