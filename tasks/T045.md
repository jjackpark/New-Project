### adversarial-reviewer 재검토 및 수정 (2026-09-17)

`done` 전환 전 적대적 리뷰에서 치명적 버그 4건 + 중요 버그 8건이 나와 전부 수정함(브라우저로 실측 재검증 완료):

- **C3(치명)**: `created_at`이 실제 API 연동 시 `"YYYY-MM-DD HH:MM:SS"`로 오면 10자 `date`와 문자열 완전일치 비교가 영원히 실패 — `sameDate()` 헬퍼(앞 10자만 비교)로 교체. 전체 datetime 문자열로 재현 테스트해 이슈/알람이 정상 집계됨을 확인.
- **C4(치명)**: 이슈 제목/일보 내용/알람 내용에 개행이나 `■`가 들어오면 리포트 포맷이 깨지거나 가짜 섹션 헤더가 생김 — `oneLine()` 헬퍼로 한 줄 정규화. 개행+위조헤더 문자열로 재현 테스트해 한 줄로 정규화됨을 확인.
- **C2(치명)**: 일보 "작성완료 N/M"에서 분자(전체 일보 개수)와 분모(현재 설비 수)가 다른 모집단이라 고아 데이터 시 `N>M` 가능 — 분자를 `equipment` 순회 중 매칭된 건수로 변경.
- **M1**: 업체별 인원 합계가 삭제된 업체의 유령 카운트까지 더해 화면에 나열되는 값의 합과 달랐음 — `vendors` 목록 기준으로만 합산하도록 수정(`app-report.js`, `dailyreports.js` 둘 다).
- **M2**: 설비 status가 enum 밖 값이면 분포 합계가 총 대수보다 작아짐 — "미분류" 버킷 추가.
- **M3**: 미래/과거 날짜를 골라도 헤더가 항상 "금일"이라 오해 소지 — 오늘이 아니면 날짜를 그대로 라벨로 사용.
- **M9**: `App.fmt.today()`가 `toISOString()`(UTC) 기준이라 KST 오전 9시 이전엔 하루 밀림(SPEC상 "아침 회의" 사용 시점과 충돌) — 로컬 날짜로 직접 조립하도록 수정.
- **M11**: 프로젝트를 못 찾으면(`pid` null 등) 빈 값으로 채워진 "정상처럼 보이는" 리포트가 나와 그대로 복사/발송될 위험 — 명확한 경고 텍스트로 대체.
- 사소: `masterPlanSection` 헤더에 건수 표기 추가(다른 섹션과 통일).
